## 새 도구 추가하는 법

`index.html` 아래쪽 `PROJECTS` 목록 맨 위에 한 덩어리를 복사해서 넣으면 돼요.

```js
{
  name: "도구 이름",
  desc: "한 줄 설명",
  url: "https://dalyeoneo-cmd.github.io/저장소이름/",
  icon: "https://dalyeoneo-cmd.github.io/저장소이름/icons/icon-192.png",
  tags: ["분류", "휴대폰 · 패드 · PC"],
  added: "2026-11-04"
},
```

`added` 날짜가 30일 안이면 NEW 표시가 자동으로 붙어요.
